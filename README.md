# findit

Private, edge-only system that remembers where everyday objects were last seen
(keys, sunglasses, earbuds, books, …) using static room cameras and mobile
cameras (phone, smart glasses). All models run inside the home or office.
**No video is ever stored**; only object-crop embeddings and metadata.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the system design, model
choices, privacy architecture, and implementation roadmap.
